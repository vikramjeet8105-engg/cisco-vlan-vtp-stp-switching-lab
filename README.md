# Layer 2 switching: VLANs, VTP, DTP and STP

| File | What it shows |
|---|---|
| `vlan-vtp.pkt` | VLAN creation and VTP server and client propagation |
| `dtp-trunking-inter-vlan.pkt` | DTP negotiation (dynamic auto and desirable), trunk links and router-on-a-stick sub-interfaces for inter-VLAN routing |
| `stp-root-bridge.pkt` | Spanning Tree: primary and secondary root bridge per VLAN, root and designated ports |
